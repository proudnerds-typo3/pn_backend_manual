**The editor manual lives where editors work: in the TYPO3 backend.**

A sitepackage or custom extension ships its manual as a Markdown file, right
next to the code it describes. Editors open it from their dashboard: a widget
with the introduction and the chapters, and a full view with a table of
contents that shows where they are.
